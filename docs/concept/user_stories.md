# Athlify – User Stories

Abgeleitet aus dem Softwarekonzept (`docs/athlify_concept.md`). Priorisiert nach MoSCoW (Must/Should/Could Have).

| ID    | Modul                   | User Story                                                                                                                                                                                                             | Akzeptanzkriterien                                                                                                                                                                                                                                    |  Priorität  |
| ----- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------: |
| US-01 | Projektwebsite          | Als Interessent möchte ich auf der öffentlichen Projekt-/Dokumentationswebsite Features und Installationsanleitung sehen, damit ich verstehe, was Athlify bietet und wie ich es selbst per Docker Compose hosten kann. | Webseite ohne Login erreichbar, unabhängig von der laufenden Athlify-Instanz betrieben; Bereiche Features, Open Source/Lizenz, Installation (`docker-compose.yml`), GitHub-Link, FAQ, Kontakt vorhanden; Link zur Applikation (Login-Seite) sichtbar. |  Must Have  |

## Nicht enthaltene Anforderungen

Aus Platzgründen (max. 20 Stories) wurden folgende Detailanforderungen des Konzepts in bestehende Stories integriert statt als eigene Story geführt:

- Vergleich zweier Zeiträume im Dashboard → Teil von **US-17** (Could Have, spätere Erweiterung).
- Konfliktbehandlung bei gleichzeitiger manueller Bearbeitung und Strava-Sync → technische Regel innerhalb **US-10** / **US-12**, kein eigenständiger Nutzerwert.

## Offene Frage zu US-19

Der Mockup `docs/AthlifyV2.html` positioniert Athlify als Open-Source-Projekt (MIT-Lizenz, GitHub Repository, Docker Compose). Ob **US-19** (kostenpflichtige Subscription) in dieser Form bestehen bleibt oder angepasst/entfernt werden muss, ist ungeklärt – siehe [Abschnitt 20 „Offene Fragen" (Kritisch)](../athlify_concept.md#20-offene-fragen) im Hauptkonzept.
