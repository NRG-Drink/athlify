Hallo Michael

Wir (Marco und Beat) möchten gerne eine App entwickeln (Athlify), die 
Trainigsdaten hübsch darstellt.
Dabei sollen Trainingsdaten von Strava importiert oder manuell 
eingegeben werden können.

User Management
     Userauth to show correct data
     Manage user-auth (refresh token, etc.) from Strava
     Optional: TFA
Security
     Admin, Normal user
     Optional: Guest/Trial user
Acitvity Management (Strava, Manuell)
     Load activities from Strava
     Edit activities
     Add activities manually
     Delete activities
Vehicle Management
     Load vehicles from Strava
     Edit vehicles
     Add vehicles manually
     Delete vehicles
     Optional: Manage images
Dashboard (Charts)
     Show activity data in charts (see wireframes/mockups)
     Optional: Compare two timeranges
     Optional: Generate report
     Optional: Export data (Vehicles and Activities)
     Optional: Multilanguage (EN, DE, CH)

Technologies
     Frontend: React + Typescript + Vite
     Backend: C# (ASP.NET) or Typescript (Next.js)
     Database: Postgres
