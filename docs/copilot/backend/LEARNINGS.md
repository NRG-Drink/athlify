behavior belongs in the concept and PRD; implemented behavior is confirmed
against source code and tests.

- 2026-09-23 - `backend` `verified` GraphQL types are discovered by Hot Chocolate source generation. Declare operations in `[QueryType]` / `[MutationType]` `static partial` classes. The generated registration method is `AddTypes()`, named after `[assembly: Module("Types")]`. Why: A resolver class that is not `static partial`, or a renamed module, silently drops operations from the schema. Evidence: [`ModuleInfo.cs`](../../../src/backend/Athlify.Api/Properties/ModuleInfo.cs), [`BodyStatsQuery.cs`](../../../src/backend/Athlify.Api/Domain/Body/BodyStatsQuery.cs), [`Program.cs`](../../../src/backend/Athlify.Api/Program.cs).
- 2026-09-23 - `backend` `procedure` Endpoint tests use TUnit's `TestWebApplicationFactory<Program>` through `WebApiTestBase`, which replaces `IDbSeeder` with `SeedNothing` so each test host starts with an empty database, and `ICurrentUser` with `TestCurrentUser` (user id from the `X-Test-User-Id` header). Tests get a signed-in client from `CreateUserClientAsync(email)`; a plain `Factory.CreateClient()` is anonymous and every domain operation then returns `NOT_AUTHENTICATED`. `Program` must stay `public partial` for the factory. Why: Tests that expect seeded data or forget the user client fail, and removing `public partial` breaks the test host. Evidence: [`MyWebApplicationFactory.cs`](../../../src/backend/Athlify.Api.Tests/MyWebApplicationFactory.cs).

- 2026-09-30 - `cross-cutting` `open` In the dev container, Aspire starts PostgreSQL on the host Docker daemon (docker-outside-of-docker) and passes the API `localhost:<published port>`, which points at the dev container itself and causes `NpgsqlException: The operation has timed out`. The container therefore runs with `--network=host` (`runArgs` in `devcontainer.json`, added 2026-10-01). Why: Without it the API cannot reach the database. Verify after the next container rebuild and then change the status to `verified`. Evidence: [`devcontainer.json`](../../../.devcontainer/devcontainer.json), [`AppHost.cs`](../../../src/backend/Athlify.AppHost/AppHost.cs).
- 2026-10-01 - `cross-cutting` `verified` Aspire resources show as `running` inside the dev container while their endpoints are unreachable from the host, because DCP binds every endpoint (including the dashboard) to `127.0.0.1` inside the container and the container had no published ports; `remote.autoForwardPorts` in `devcontainer.json` is a VS Code setting and is inert under JetBrains Gateway. Diagnose with `docker exec <container> ss -ltnp` (expect `127.0.0.1:<port>`) and `curl http://127.0.0.1:<port>` inside versus outside the container. Why: The resource is healthy, so only the network path explains the failure. Evidence: [`devcontainer.json`](../../../.devcontainer/devcontainer.json), [`AppHost.cs`](../../../src/backend/Athlify.AppHost/AppHost.cs).
- 2026-10-03 - `backend` `procedure` On .NET 10, TUnit tests do not run through `dotnet test` ("Testing with VSTest target is no longer supported"). Run `dotnet run --project Athlify.Api.Tests` from `src/backend/`. While Aspire runs the API from the same folder, add `--artifacts-path <dir>` so the build does not hit the locked `apphost` ("Text file busy"). Why: The default commands fail for reasons unrelated to the code. Evidence: [`Athlify.Api.Tests.csproj`](../../../src/backend/Athlify.Api.Tests/Athlify.Api.Tests.csproj).
- 2026-10-03 - `backend` `verified` `Program.cs` registers the DbContext with `AddDbContext` + `UseNpgsql` and `EnrichNpgsqlDbContext` (since 2026-10-07; previously `AddNpgsqlDbContext`), which fails at startup without `ConnectionStrings:postgres-db`. `MyWebApplicationFactory` supplies a dummy value and swaps the registrations for EF Core InMemory, one database per factory. Why: Without it every endpoint test fails with "ConnectionString is missing" and no PostgreSQL is needed for tests. Evidence: [`MyWebApplicationFactory.cs`](../../../src/backend/Athlify.Api.Tests/MyWebApplicationFactory.cs).
- 2026-10-03 - `backend` `pitfall` TUnit creates a new web factory, and so a new empty database, for every test. Tests chained with `[DependsOn]` that rely on data from an earlier test fail. Each test creates its own data (see `BodyStatsGraphQl.cs`). Why: The old chain only worked while all tests shared one database. Evidence: [`BodyStatsMutationTests.cs`](../../../src/backend/Athlify.Api.Tests/BodyStatsMutationTests.cs).
- 2026-10-03 - `backend` `verified` Hot Chocolate 16 global IDs: `AddGlobalObjectIdentification()`; `[ID]`, `[ID<T>]` and `[Node(NodeResolverType = …, NodeResolver = …)]` are in `HotChocolate.Types.Relay`. `[ID<T>]` is valid on properties, methods and parameters, not on a return value, so a mutation that returns an ID carries it on the method. Clients receive opaque strings, so tests read `id` as a string. Why: The compiler errors do not name the namespace. Evidence: [`BodyStatsMutation.cs`](../../../src/backend/Athlify.Api/Domain/Body/BodyStatsMutation.cs), [`BodyStats.cs`](../../../src/backend/Athlify.Api/Domain/Body/BodyStats.cs), [`ADR-006`](../adr/ADR-006-relay-global-ids.md).
- 2026-10-03 - `backend` `verified` The committed frontend `schema.graphql` can be produced from the test host with `GET /graphql?sdl` when the running API still has the old schema. Delete removes a measurement's notes explicitly because the existing PostgreSQL foreign key has no cascade. Why: Schema export and delete would otherwise depend on restarting the Aspire app or on a migration. Evidence: [`BodyStatsMutation.cs`](../../../src/backend/Athlify.Api/Domain/Body/BodyStatsMutation.cs).
- 2026-10-03 - `backend` `verified` Cursor paging in Hot Chocolate 16.6 with EF Core: the field is a `static` method taking `PagingArguments` and `QueryContext<T>`, ordered through `.With(query, sort => sort.AddDescending(date).AddDescending(id))`, and returns `new PageConnection<T>(await ….ToPageAsync(pagingArgs, ct))`. Do not add `[UsePaging]` (schema build fails) and do not return a bare `Page<T>` (HC then pages the list again with index cursors and `hasNextPage` is wrong). `ModifyPagingOptions` raises the default maximum of 50, and a page of 1000 with nested notes exceeds the default query cost limit. Why: Each of these produced a silent or confusing failure. Evidence: [`BodyStatsQuery.cs`](../../../src/backend/Athlify.Api/Domain/Body/BodyStatsQuery.cs), `ListIsAConnectionThatPagesWithoutSkippingOrRepeating` in [`BodyStatsQueryTests.cs`](../../../src/backend/Athlify.Api.Tests/BodyStatsQueryTests.cs).
- 2026-10-04 - `cross-cutting` `verified` In a JetBrains dev container session (WebStorm 2026.2 split mode) the Markdown preview is rendered by the local thin client, which does not load the bundled Mermaid plugin (it depends on the backend-only module `intellij.json.backend`). - 2026-10-07 - `backend` `verified` Ownership is enforced by EF Core 10 named query filters that read `ICurrentUser` through a DbContext member (`HasQueryFilter("Owner", e => e.UserId == CurrentUserId)`). The context must not be pooled: Aspire's `AddNpgsqlDbContext` pools, so register `AddDbContext` and call `EnrichNpgsqlDbContext<T>()` to keep Aspire's retries, health check and telemetry. A `GraphQLException` thrown by the user getter while EF evaluates the filter reaches the client unchanged (`NOT_AUTHENTICATED`). Named filters and `IgnoreQueryFilters(["NotDeleted"])` work on the InMemory provider. Why: A pooled context or an unnamed `IgnoreQueryFilters()` would silently leak other users' records. Evidence: [`AthlifyDbContext.cs`](../../../src/backend/Athlify.Api/Database/AthlifyDbContext.cs), [`Program.cs`](../../../src/backend/Athlify.Api/Program.cs), [`OwnershipTests.cs`](../../../src/backend/Athlify.Api.Tests/OwnershipTests.cs).
- 2026-10-07 - `backend` `pitfall` A mutation or `node(id:)` resolver that returns a tracked entity only has the navigations it `Include`s, so `createActivity { vehicle { tags } }` returned empty vehicle tags while the list was correct. Inject `QueryContext<T>` into mutations and node resolvers too and return the record through `Projection.FirstOrDefaultAsync` (`Where(id).With(query, s => s)`), the same projection the lists use; properties with a private setter project fine. Why: Relay writes the mutation result into its store, so missing nested data overwrites correct data in the UI. Evidence: [`Links.cs`](../../../src/backend/Athlify.Api/Domain/Common/Links.cs), `CreateReturnsLinksIncludingNestedOnes` in [`ActivityTests.cs`](../../../src/backend/Athlify.Api.Tests/ActivityTests.cs).
- 2026-10-07 - `backend` `verified` Hot Chocolate's cost analysis rejects a filtered page of 200 activities (field cost 6626, limit 1000) because a `where` argument passed as a variable, as Relay does, is multiplied as worst case; nested lists without `@listSize` count as one item, and `[ListSize(AssumedSize = n)]` makes the type cost worse, not better. Send the header `GraphQL-Cost: report` to see `operationCost`. The limits are raised with `ModifyCostOptions` (`MaxFieldCost`, `MaxTypeCost` = 10,000). Why: The default limits target public APIs and broke the main Activities query. Evidence: [`Program.cs`](../../../src/backend/Athlify.Api/Program.cs), `FilterByPeriodTypeTagAndBicycle` in [`ActivityTests.cs`](../../../src/backend/Athlify.Api.Tests/ActivityTests.cs).
- 2026-10-07 - `backend` `pitfall` Hot Chocolate's global usings include `HotChocolate.Types`, which has a `Tag` type, so the domain `Tag` is ambiguous (CS0104) in every file that imports it. `Athlify.Api.csproj` declares a global alias `Tag` = `Athlify.Api.Domain.Tags.Tag`. Avoid domain type names that collide with `HotChocolate.Types`. Why: The error appears in unrelated files as soon as a new area imports tags. Evidence: [`Athlify.Api.csproj`](../../../src/backend/Athlify.Api/Athlify.Api.csproj).
- 2026-10-07 - `backend` `durable-rule` Endpoint tests run on EF Core InMemory, which supports neither `ExecuteUpdate`/`ExecuteDelete` nor transactions and does not enforce unique indexes, check constraints or foreign-key actions. Load dependents and change them explicitly before one `SaveChanges` (for soft-deleted activities with `IgnoreQueryFilters(["NotDeleted"])`), and check every rule in code before saving. Verify database constraints and migrations manually against PostgreSQL (for example a throwaway `postgres` container and `--ConnectionStrings:postgres-db=…` on `dotnet run`). Why: Rules that only exist in the database are invisible to the test suite ([ADR-011](adr/ADR-011-ef-core-migrations.md)). Evidence: [`VehicleResolvers.cs`](../../../src/backend/Athlify.Api/Domain/Vehicles/VehicleResolvers.cs), [`ActivityMerge.cs`](../../../src/backend/Athlify.Api/Domain/Activities/ActivityMerge.cs).
- 2026-10-07 - `cross-cutting` `pitfall` A PostgreSQL volume created by the prototype's `EnsureCreated` has no `__EFMigrationsHistory`, so `MigrateAsync` fails at startup with "relation already exists". Remove the Aspire volume once with `docker volume rm athlify-postgres-data`. Why: The error looks like a broken migration but only the old volume is wrong. Evidence: [`CONFIGURATION.md`](../../CONFIGURATION.md#database-migrations), [`Program.cs`](../../../src/backend/Athlify.Api/Program.cs).
- 2026-10-07 - `backend` `verified` Hot Chocolate 16.6.4 shapes an entity from a separate class: `[ObjectType<T>] public static partial class XObjectType` with `static partial void Configure(IObjectTypeDescriptor<T> descriptor)`, where `descriptor.ImplementsNode().IdField(x => x.Id).ResolveNodeWith(typeof(XNode).GetMethod(nameof(XNode.GetAsync))!)` replaces `[Node(...)]` and `descriptor.Ignore(x => x.Prop)` replaces `[GraphQLIgnore]`. Why: Entities stay free of API attributes. Evidence: [`TagObjectType.cs`](../../../src/backend/Athlify.Api/Domain/Tags/TagObjectType.cs), [`ArchitectureTests.cs`](../../../src/backend/Athlify.Api.Tests/ArchitectureTests.cs).
- 2026-10-07 - `backend` `pitfall` Filter and sort inputs are inferred from the CLR property, not from the type extension: without `[ID]` on `Entity.Id` the `id` filter becomes `IntOperationFilterInput` and Relay string ids fail with "Int cannot coerce". Keep that one attribute on `Entity.Id`. Also, `Ignore()` in the type extension hides the field everywhere, but the unreferenced list filter of an ignored navigation (`ListFilterInputTypeOfEventFilterInput`) still appears in the SDL. Why: A schema diff after moving attributes is otherwise surprising. Evidence: [`Entity.cs`](../../../src/backend/Athlify.Api/Domain/Common/Entity.cs).
- 2026-10-07 - `backend` `verified` Input records can inherit: `VehicleInput : EquipmentInput` exposes the inherited properties including `[ID<Tag>] TagIds`, and a class named `XInput` becomes the GraphQL type `XInput` (no doubled suffix, no `Dto`). A non-entity abstract base (`Equipment : Entity, IOwned`) adds no table: `dotnet ef migrations has-pending-model-changes` reports no changes. Why: Shared fields of bicycles and gadgets live once. Evidence: [`Equipment.cs`](../../../src/backend/Athlify.Api/Domain/Common/Equipment.cs), [`EquipmentInput.cs`](../../../src/backend/Athlify.Api/Domain/Common/EquipmentInput.cs).
- 2026-10-07 - `backend` `durable-rule` The committed `schema.graphql` is Hot Chocolate's raw SDL (not Prettier-formatted); the generated Relay files in `__generated__/` are Prettier-formatted and git-ignored. Re-export it from the test host and compare with `sort` on both files, because a refactor can reorder fields without changing the contract. Why: A formatted schema file creates a large noisy diff. Evidence: [`schema.graphql`](../../../src/frontend/athlify/schema.graphql).
